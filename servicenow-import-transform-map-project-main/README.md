# ServiceNow - Import Data using Transform Maps (Spreadsheet)

## Project Overview

This micro project demonstrates an end-to-end employee data import workflow in ServiceNow using an external spreadsheet, Import Sets, Transform Maps, field mapping, Coalesce, Reports, and a Dashboard.

Employee data is prepared in spreadsheet format, loaded into an Import Set staging table, transformed into a custom Employee Test table, validated, and then presented through reports and an Employee Analytics Dashboard.

## Project Objectives

- Prepare structured employee data in spreadsheet format.
- Create a custom Employee Test table in ServiceNow.
- Load spreadsheet data into an Import Set table.
- Create and configure a Transform Map.
- Map source fields to target fields.
- Execute and validate the transformation.
- Enable Coalesce using Employee ID to avoid duplicate records.
- Demonstrate inserted and updated records.
- Create employee reports.
- Create an Employee Analytics Dashboard.

## Coalesce

The Transform Map uses Employee ID as the Coalesce field.

The purpose is to identify an existing employee during a later import. If the Employee ID already exists, the record can be updated instead of creating another employee record. New Employee IDs are inserted.

## Reports

The project contains three reports:

1. **Employees by Department**
   - Table: Employee Test
   - Type: Pie Chart
   - Group By: Department
   - Aggregation: Count

2. **Employees by Location**
   - Table: Employee Test
   - Type: Bar Chart
   - Group By: Location
   - Aggregation: Count

3. **Employee List Report**
   - Table: Employee Test
   - Type: List
   - Columns: Employee ID, Employee Name, Email, Department, Location

## Dashboard

The reports are combined into:

**Employee Analytics Dashboards**

The dashboard provides a centralized view of employee data through charts and an employee list.
